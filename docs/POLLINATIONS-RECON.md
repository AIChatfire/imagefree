## 3. 频控模型（✅ 三层全钉死）

1. **每 IP 准入队列深度 1**（匿名）：并发第 2 条起**秒拒 429**，正文机读
   `queueInfo:{ip,maxAllowed:1,tier,pending}`，无 Retry-After 头，带付费 CTA。
2. **模型级 per_user_rpm**：sana/dreamshaper=300，flux/zimage/klein=60（gen 目录元数据）。
3. **共享社区池**：`community_model_rate_limit`（"Per-user limit of 300 RPM exceeded"）
   → 对外报**哑 500**（池子出口也会撞，实测 3/11）。两类失败要分开对待：
   queue-full 429=等在途完成重试；哑 500=退避重试。

文档层级限速：Anonymous 1 req/15s → Seed(免费注册) 1/5s → Flower 1/3s → Nectar 无限。

**哑 500 的 IP 依赖性（✅ 交叉重试实验）**：池子 burst 8 条 → 6×200 + 2×哑500；
对 500 条目**立刻**换路重试——直连 200（2.5s / 41s 排队）、池子新连接 200（~1s），
两条路都通且字节相同 ⇒ **500 是瞬态共享桶（秒级自愈），与出口 IP 无关**。
对策：429 类换池子立刻好；500 类等几秒原地重试即可，换不换路无所谓。

## 4. 429 → SOCKS5 池回退（✅ 已验证）

- 池：`socks5h://…@pool.****:2088`（地址已打码），**每连接轮换出口 IP**（38.6.213.x 段）
  ⇒ 每连接 = 一个新队列。
- 实测：直连 4 并发 → 1×200 + 3×429；3 条 429 **同 URL** 走池子 → 3×200。
  429=上游什么都没建 ⇒ 同 URL 重试零浪费（与 imagefree 结论一致）。
- 复用脚本：`~/.workbuddy/scripts/pollfetch.sh`（直连优先、429 自动走池，`POLL_POOL` 可换池）。

## 5. 缓存模型（✅ 最终修正版——此前"归一化键"假设作废）

**键 = 完整原始 URL，无任何归一化；单层全局缓存，跨出口 IP 共享，条目长期存活。**

- 直接证据：`lot1-3` 同裸 URL 三连全 HIT 同字节；`g1`(池) MISS → `g2`(直连) HIT 同字节。
- "不同查询串像素相同"（cat 带参 vs 裸）不需要归一化解释：**缺省参数解析后是同一确定性渲染**，
  各自作为独立条目被不同请求者先后填充而已。
- "z=1 击穿"是错觉：z 参数从未进键——那条 URL 只是**恰好没人请求过**（MISS 现场生成）。
- 确定性：同引擎窗口内同参数渲染 **byte 级复现**（d1≡d2、s4b≡s4c、k2≡s4b 三重验证）；
  默认 seed 为**固定值**（非随机）；跨引擎版本漂移后不复现（今天重渲染 ≠ 政策前老缓存）。
- 实践准则：判"同图"用**像素差**不用 md5（缓存条目间有 EXIF/编码器字节噪声）。

## 6. 水印能否去除——最终结论

**能，三条有效路径（按场景选）：**

| 路径 | 有效性 | 适用 | 代价 |
|---|---|---|---|
| ① 注册 Seed 层 → `nologo=true` 生效 | ✅ 官方确定（文档+门控证据，未亲测需账号） | 规模化/正规用途，唯一**事前**解 | 免费注册 |
| ② 捡政策前遗留缓存 | ✅ 实测（cat/apple/sunset 等 4 条命中） | 匿名 + 老牌教程 prompt，撞运气 | 免费，命中率低（总 4/14） |
| ③ 事后 inpaint 修复 | ✅ 实测（复杂纹理角 2×/3× 放大无痕） | 已有带水印的图 | 一次后处理 5~9ms |

**无效路径（同样实测钉死）：** 换 IP/代理池 ❌（水印按生成时身份烙印，池子出口照样带标）；
调参数 ❌（`nologo`/`z`/尺寸/seed 全试过，匿名恒打标）。

**③ 的质量阶梯（实测）**：默认 = TELEA + **颗粒匹配**（环形邻域测 σ 补高频噪声，
修复区纹理统计贴近周围；A/B 3× 特写沥青/木纹更自然，+2ms）；NS 变体与 Telea 无肉眼差；
LaMa/IOPaint 是上限但需 torch 系重依赖（已按"轻量"要求放弃，仅当水印压在文字/人脸等
结构化内容上才值得装）。水印核心像素 ≈44-48% 纯白 ⇒ **不透明**，"反解被遮像素"路线不成立。

**推荐**：认真用就注册（免费、一劳永逸、顺带解锁 1/5s 限速与标准模型）；
手头已有水印图跑仓内 CLI：`python scripts/remove_watermark.py 图.jpg ...`（核心在
`app/watermark.py`，三档判定 + 颗粒匹配，离线零额度，173 用例覆盖）；捡缓存只当彩蛋。
